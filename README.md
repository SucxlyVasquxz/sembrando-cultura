# Sembrando Identidad 🌱
### Plataforma Escolar de Concientización sobre la Identidad Cultural y el Sentido de Pertenencia

**Sembrando Identidad** es una iniciativa interactiva diseñada para comunidades escolares (estudiantes, docentes, directivos y familias) con el propósito de reflexionar, valorar y defender las raíces culturales, la memoria comunitaria y las lenguas originarias frente a la homogeneización y el desarraigo social.

---
## 🎯 Objetivos de la Plataforma

1. **Para Alumnos:**
   - Superar la vergüenza lingüística y cultural ocasionada por burlas, modas digitales o presión social.
   - Conectar con sus antepasados y adultos mayores a través de la investigación de su historia oral y recetas familiares.
   - Reconocer que la cultura propia no es anticuada, sino el motor de creatividad más auténtico e innovador.

2. **Para Profesores y Directivos:**
   - Proporcionar herramientas pedagógicas para una interculturalidad cotidiana y transversal (no reducida a festivales aislados).
   - Combatir el bullying discriminatorio por acento, vestimenta o procedencia.
   - Facilitar dinámicas de aula listas para usar y copiar directamente a sus planeaciones.

---

## 🧭 Estructura y Módulos de la Aplicación

- **Panorama y Causas:** Diagnóstico de los factores que provocan la pérdida de identidad (homogeneización digital, acoso escolar, ruptura intergeneracional, currículos descontextualizados) y sus consecuencias invisibles.
- **Mitos vs. Realidades:** Sección interactiva para desarmar falsas creencias sobre la tradición y la modernidad.
- **Importancia de la Pertenencia:** Los 4 pilares: salud socioemocional, prevención del bullying, creatividad crítica y defensa comunitaria.
- **Zona Estudiantil:** Pilares de empoderamiento, retos semanales ("Siembra tu raíz") y preguntas para reflexionar frente al espejo.
- **Guía Docente:** Principios de aula inclusiva y lista de verificación (checklist) interactiva de autodiagnóstico docente.
- **Banco de Dinámicas:** Fichas didácticas completas ("El Árbol de Nuestras Raíces Vivas", "Cápsula del Tiempo: Voces de los Sabios", "Feria de Saberes y Sabores", "Taller: Deconstruyendo el Estereotipo") con botón para copiar a la planeación escolar.
- **Test Interactivo "Mi Brújula Cultural":** 5 preguntas reflexivas con retroalimentación formativa y diagnóstico de nivel de pertenencia.
- **Decálogo Escolar Imprimible:** 10 principios institucionales listos para imprimir o colocar en el periódico mural escolar.
- **El Muro de las Semillas:** Espacio participativo donde alumnos y maestros publican sus compromisos de preservación cultural (almacenados localmente con sistema de apoyos/likes).

## 🚀 Cómo ejecutar el proyecto

```bash
# 1. Entrar a la carpeta del proyecto
cd sembrando

# 2. Instalar dependencias (si es necesario)
npm install

# 3. Iniciar el servidor de desarrollo
npm run dev

# 4. Construir para producción
npm run build
```
